# Arquivos da marca Ágape

Adicione aqui os arquivos oficiais fornecidos pelo cliente, preservando a proporção:

- `agape-logo.png` — versão completa para header e footer
- `agape-simbolo.png` — símbolo isolado para favicon

Depois, atualize `company.brand.logoPath` e `company.brand.symbolPath` em `src/data/company.ts`.
