# Ágape Instalações — site corporativo

Site institucional, portfólio e canal de solicitação de orçamento da **Ágape Instalações**.

## Tecnologias

- React 19
- TypeScript
- Vite 7
- Tailwind CSS 4
- Lucide React

## Execução local

```bash
npm install
npm run dev
```

Validação de produção:

```bash
npm run lint
npm run build
```

## Conteúdo provisório

Contatos, indicadores, projetos, missão, visão, área de atendimento e imagens técnicas estão centralizados em `src/data/` e marcados com `TODO CLIENTE` quando precisam de confirmação. O logotipo oficial deve ser incluído em `public/brand/` conforme as instruções da pasta.
